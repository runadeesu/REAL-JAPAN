# PROJECT: REAL JAPAN

「現実世界そのものをゲームにする」——実在の日本を、公的な地理・建物データから再構築して、その中で生活できるオープンワールドゲーム。

**現在：v0.5.0（開発ビルド）/ Windows 10・11 x64 ネイティブ EXE**

2 つのワールドを収録：**秋津国（架空）**＝日本の風景を参考に手続き生成した架空の国（既定）、**渋谷**＝PLATEAU・国土地理院の実データ（`--world shibuya` または settings.ini の `world = shibuya` で切替）。

### v0.5.0 の新要素：島から「国」へ（秋津国）

- **国土**：本島 約 50 × 38 km＋南島（10 × 7 km）。背骨の秋津山脈（最高 約 1,400 m）、成層火山 **焔岳**（1,850 m、山頂火口）、山あいの湖 焔湖、5 本の川（山から平野へ蛇行）、平野・盆地、入り組んだ海岸と砂浜
- **都市と町**：首都 **千景**（v0.4 の島の街をそのまま首都に）、千景北、碁盤の目に町家が並ぶ古都 **紫苑**（東山の寺、千本鳥居の神社）、港町 **朝凪**（コンテナ港のガントリークレーン、丘の上の城）、山あいの **湯の沢温泉**（旅館・ホテル）、雪国の **雪見**（急勾配の金属屋根）、南島の **島ノ浦**、12 の農村（大屋根の農家と納屋）
- **田園**：山の斜面の森林（樹冠）、平野と谷の**水田**（畦と農道、季節で 水張り→青田→黄金色→刈り取り）、畑、火山の草原と裸地。**冬は北側と高地に雪**（ゲーム内の日付で季節が変わる）
- **交通**：**秋津新幹線**（千景中央—千景北—紫苑—新朝凪、最高 300 km/h）、**雪見新幹線**（千景北—湯の沢温泉—長いトンネル—雪見）、在来線 **秋津本線**（首都西部の西ヶ丘—山麓—稲穂—高瀬—紫苑—楓—朝凪、曲線の制限速度つき）、環状線。線路は勾配を抑えて谷を橋で渡り尾根をトンネルで抜ける（坑口・切通し）。運賃は距離制（IC カード、ゲーム上の値）。国道網と山越えの道・火山のスカイライン。**2 つの空港を結ぶ定期便**（千景空港 ⇄ 南島空港：離陸・巡航・進入・着陸まで地図上で飛ぶ）、**3 航路のフェリー**（港内船・高速船・カーフェリー）
- **遠景**：読み込み範囲の外も国全体の地形・色・建物の箱を低解像度で描画（山並み・火山が遠くに見える）

### v0.4.0 からの機能（首都 千景ほか）

- **電車・新幹線**：改札を通ってホームへ、環状線・秋津本線・新幹線に乗る（窓側席から車窓）、環状線は**運転士として運転**（ノッチ・非常ブレーキ・ATS・停止位置の評価）。駅に着くと**ホーム側のドアが開閉**、**乗客**（座席・つり革・ドア位置の整列乗車・降りて歩く人。混み具合は時間帯による仮定）、**架線とパンタグラフ**、**駅名標**と**LED 発車標**（あと何分・「まもなく電車がまいります」）、夜はホームの照明
- **車**：止まっている車に乗って運転（タイヤのスリップ角・荷重移動・AT・ABS 相当・サイドブレーキでのスライドを計算する車両運動モデル）、追従カメラ／運転席視点（動く速度計・回転計・ハンドル、ミラーに実際の後方映像）、クラクション。AI の車は交差点の手前でウインカー
- **フェリー**：桟橋から乗船、甲板を歩いて航行（離岸・回頭・着岸・うねり・航跡）。航路の両端の港とも収録
- **飛行機**：空港ターミナルから定期便に搭乗して窓側席で離着陸（他の乗客も座っている）、もう一方の空港に着く、**小型機を操縦**（6 自由度の飛行モデル、操縦席の 6 計器）
- **音（すべてプログラムで合成、録音・素材は不使用）**：エンジン音・タイヤ音、すれ違う車のドップラー効果、レールの継ぎ目の音・インバータ音・きしみ、新幹線の風切り音、オリジナルの発車メロディとドアチャイム、汽笛、客室騒音、小型機のエンジンと失速警報、街のざわめき・信号の誘導音・カラス・雨・足音
- **仕事**：タクシー運転手（東京の運賃体系のメーター）、配達員、電車の運転士、コンビニのレジ、その他 51 職業の簡易シフト
- **趣味**：釣り、写真（撮影スポット）、神社・寺の参拝（おみくじ・御朱印）、散歩の記録

※ 国・地名・路線・駅・会社・船・航空会社はすべて架空（実在の地名・店名・社名は使っていません）。数値（運賃・運行本数・報酬・魚の大きさ・おみくじの割合・車両や機体の諸元）はゲーム上の値で、統計や実在の諸元ではありません。設計の詳細と未実装の一覧は [docs/COUNTRY.md](docs/COUNTRY.md)。

## 構成

```
core/       rjcore：エンジン非依存のシミュレーションコア（C++20, テスト 49 件）
client/     ネイティブゲームクライアント（C++20 + raylib, Windows x64 / Linux）
pipeline/   実データ → ゲームデータ（PLATEAU CityGML, 国土地理院 DEM）、架空の国の生成（country/, cook_country.py）
game/data/  言語ファイル・既定設定（街データとフォントはスクリプトで生成／取得）
packaging/  Windows 配布物の README とデータ出典
tools/      依存取得・アイコン生成・配布 ZIP 作成・品質確認スクリーンショット（shots.sh, shots_country.sh）
```

## データ出典

- 「3D都市モデル（Project PLATEAU）渋谷区（2025年度）」（国土交通省）（https://www.geospatial.jp/ckan/dataset/plateau-13113-shibuya-ku-2025）を加工して作成
- 出典：国土地理院 標高タイル（https://maps.gsi.go.jp/development/ichiran.html）を加工して作成 ※焼き込み配布に関する測量法上の手続き要否は確認中

Google Maps / Earth 等の著作物は抽出していません。PLATEAU の写真テクスチャ（航空写真由来）には実在の看板・広告が写り込んでおり、第三者の商標・著作物の扱いは確認中です（ゲーム内の設定で写真テクスチャをオフにできます）。
