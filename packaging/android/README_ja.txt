PROJECT: REAL JAPAN  —  Android 版 開発ビルド v0.8.0（試作）
======================================================================

Windows 版と同じゲーム（秋津国〈架空〉と渋谷〈PLATEAU 実データ〉の 2 ワールド）を、
Android 向けに OpenGL ES 3.0 で動くようにしたものです。画面のタッチ操作に対応しています。

■ 最初に正直に
  ・このビルドは実機（スマートフォン・タブレット）でまだ一度も動かしていません。
    Linux 上で同じ描画コード（OpenGL ES 3.0 / Mesa）と、全シェーダの GLSL ES 3.00 の
    厳密検証までは確認済みです。インストールできない・起動しない・重いなどが起きる
    可能性があります。
  ・対応：Android 7.0 以上、64bit ARM（arm64-v8a）、OpenGL ES 3.0 対応 GPU。
    32bit 端末・x86 端末（多くのエミュレータ）では動きません。
  ・署名はリポジトリに入っている公開のデバッグ鍵です（Google Play 配布版ではありません）。

■ ファイル
  RealJapan-0.8.0-android-arm64-full.apk   これ 1 つに全部入っています（約 560MB）

■ インストール方法（どちらか）
  A. スマホだけで：APK をスマホに保存してファイルアプリでタップし、「提供元不明のアプリ」の
     インストールを許可してインストール。
  B. PC から：USB デバッグを有効にして  adb install RealJapan-0.8.0-android-arm64-full.apk
  更新するときも同じように入れ直してください（署名が同じなのでセーブは残ります）。
  必要な空き容量：約 600MB（データは APK の中から直接読み、初回にコピーはしません）。
  （開発者向けに、本体＋スプリット APK に分けた形式も tools/package_android.py で作れます）

■ タッチ操作
  左半分に指を置く   : その場所がスティックになり移動（端まで倒すと走る）
  右半分をなぞる     : 見回す
  右半分を軽くタップ : 使う／調べる（照準の先の物。座る・乗る・ドア・お店のカウンター など）
  右下のボタン       : 使う・ジャンプ・視点 など（状況で変わります：運転中はサイドブレーキ・
                       ホーン、小型機は出力±・フラップ・ラダー、運転士はノッチ±・非常、
                       釣りは「巻く」、神社ではおみくじ・御朱印、給油所では「給油」、
                       ギターを持つと 1〜6 の音・バンド・しまう）
  右上のボタン       : スマホ（地図・財布・しごと など）、メニュー
  戻るボタン         : Esc と同じ（メニュー・閉じる）
  メニューやスマホの画面では、ボタンを直接タップします。地図は 2 本指で拡大・縮小。
  ※ 物理キーボードをつないだ場合は Windows 版と同じキーも使えます。
  ※ Bluetooth などのゲームコントローラーも使えます（割り当ては Windows 版の README と同じ）。

■ 画質（スマホ向けの初期設定）
  描画は縦 720 ライン相当で行い、画面いっぱいに拡大表示しています。描画距離 800m、
  画質処理（SSAO・ブルーム・反射）オフ、影オン。「設定」で変更できます
  （重いときは影をオフ、描画距離を短く）。

■ セーブ
  アプリ内部の保存領域に保存します（アンインストールすると消えます）。
  ホームボタンなどでアプリが一時停止するときにオートセーブします。

  ゲーム内容、架空の設定、データの出典と権利表示、未実装の項目は Windows 版の
  README_ja.txt と同じです（リポジトリの docs/STATUS.md に全項目の状況があります）。
  ・秋津国は架空の国です。運賃・料金・価格・報酬などの数値はゲーム上の値です。
