PROJECT: REAL JAPAN  —  渋谷 Vertical Slice（開発ビルド） v0.2.0
======================================================================

■ 起動方法
  1. ZIP を好きな場所に展開します（例：デスクトップ）。
  2. フォルダ内の「RealJapan.exe」をダブルクリックします。
     ※ インストールや追加のランタイム（DLL）は不要です。
     ※ 署名のない開発版のため、初回に「Windows によって PC が保護されました」と
        表示された場合は「詳細情報」→「実行」を選んでください。
  3. 「data」フォルダは必ず RealJapan.exe と同じ場所に置いてください。
  ※ 配布物が「-part1.zip」「-part2.zip」の2つに分かれている場合は、両方を同じ場所に
     展開してください（どちらも RealJapan-0.2.0-win64 フォルダにまとまります）。
     片方だけの場合は起動時に「街のデータファイルが見つかりません」と表示されます。

■ 動作環境
  OS     : Windows 10 / Windows 11（64bit, x64）
  GPU    : OpenGL 3.3 対応。影・SSAO・画面反射などを使うため、2016年以降の外付けGPU
           または新しめの内蔵GPUを推奨（重い場合は「設定」でポストエフェクト・影をオフ）
  メモリ : 8GB 以上推奨
  空き容量: 約 300MB

■ 操作方法
  W A S D / 矢印キー : 移動          Shift : 走る         Space : ジャンプ
  マウス             : 視点          F     : 飛行モード切替（Space 上昇 / Ctrl・C 下降）
  E                  : 調べる／入る（地下街の入口など）
  V                  : 一人称／三人称  Tab   : スマートフォン   Esc : メニュー
  F3                 : 開発者表示（座標・FPS・描画数・歩行者/車両数など）の表示切替
  F5                 : スロット1にクイックセーブ     F12 : スクリーンショット
  建物に視線を向けると、公的3D都市モデル（PLATEAU）の建物情報と検証状態が表示されます。
  人に視線を向けると、住民（シミュレーション）か来街者（統計的に生成）かが表示されます。

■ セーブデータ・設定ファイル
  セーブ   : %APPDATA%\RealJapan\saves\slot0.sav（オートセーブ）, slot1〜3.sav
  設定     : %APPDATA%\RealJapan\settings.ini（ゲーム内の「設定」から変更・自動保存）
  既定値   : data\config\default.ini
  スクショ : %APPDATA%\RealJapan\screenshots\
  ポータブル: RealJapan.exe と同じ場所に空の「portable.txt」を置くと、
              セーブと設定を userdata\ フォルダに保存します（USBメモリ運用など）。

■ 言語
  タイトル画面 →「設定」→「言語 / Language」で 日本語 ⇔ English を切り替えられます。

■ このビルドで実装されているもの（正直な一覧）
  実データ（出典のあるもの）
  ・国土交通省 PLATEAU（渋谷区 2025年度）の実在建物 9,535 棟（LOD2 詳細形状 3,064 棟）と
    航空写真由来の屋根・壁テクスチャ
  ・PLATEAU の実在道路形状：車道・歩道（段差のある歩道と縁石）・中央帯、実在の街路樹
  ・PLATEAU の都市設備（信号・照明・柵・標識・マンホール・横断歩道などの標示）
    ※調査されているのは渋谷駅東側（明治通り周辺）などの一部道路のみ
  ・PLATEAU LOD4 の渋谷駅周辺の地下街（検証済み内部）。階段から歩いて入れます
  ・国土地理院の標高データによる地形、実際の天文計算による太陽位置、日本の祝日

  推定・生成（実データではないもの。ゲーム内でも区別しています）
  ・PLATEAU に標示・信号・照明が無い道路：道路の実形状から、横断歩道・停止線・車線、
    主要交差点の信号（柱・灯器）、街路灯、細い道の電柱と電線・防犯灯を日本の一般的な
    設置方法に沿って推定配置
  ・建物の近景（店舗の間口・ガラス・看板帯・庇、窓、室外機など）。看板の文字は実在の
    店名ではない汎用の模様です（店名はデータに無いため）
  ・夜の点灯窓（写真テクスチャには無い、時間帯の在室率による表現）
  ・信号の時間（現示は非公開のため 100 秒周期の仮定）

  シミュレーション
  ・天気 10 種（快晴〜雷雨・霧・強風）、雨で濡れる路面・水たまり・傘をさす人
  ・車：実在の車道網の上を左側通行で走行、信号・停止線で停止、時間帯で交通量が変化
  ・歩行者：架空の住民（実在の建物に住む設定・1日の予定つき）＋来街者（時間帯と周辺の
    実在建物の用途・床面積、実在の駅出入口から統計的に生成。実測の人流ではありません）。
    歩道と横断歩道を歩き、赤信号では待ちます
  ・描画：物理ベースの陰影、太陽の影、SSAO、画面反射（SSR）、ブルーム、自動露出、夜の街明かり
  ・スマートフォン（地図・時計/日照・銀行・街の様子）、セーブ／ロード、日本語／英語

■ まだ実装されていないもの（NOT IMPLEMENTED）
  鉄道・飛行機・船、プレイヤーの運転、店での買い物、仕事、会話、サウンド、
  地下街以外の建物内部（公開資料が無いため捏造せず入場不可）、
  渋谷以外の地域（47都道府県）、レイトレーシング／全域照明（GI）、ボリュームライト、
  モーションブラー、写真と区別できない品質（未到達）。
  人物・車は簡易な手続き生成モデルです（専用の3Dアセットは未使用）。
  詳細: リポジトリの docs/STATUS.md

■ データ出典
  ・「3D都市モデル（Project PLATEAU）渋谷区（2025年度）」（国土交通省）
      （https://www.geospatial.jp/ckan/dataset/plateau-13113-shibuya-ku-2025）を加工して作成
      利用条件：公共データ利用規約（第1.0版）準拠・CC BY 4.0 互換（PLATEAU サイトポリシー）
  ・出典：国土地理院 標高タイル（DEM5A/DEM5B/DEM10B）
      （https://maps.gsi.go.jp/development/ichiran.html）を加工して作成
      ※本ビルドは標高を焼き込んで配布しているため、測量法上の手続き要否を確認中です（開発版）。
  詳細は LICENSES\DATA_SOURCES.txt
  建物名はPLATEAUの名称属性をそのまま表示しています。
  PLATEAU の写真テクスチャには実在の看板・広告が写り込んでいます（第三者の権利の扱いは確認中）。
  「設定」→「建物の写真テクスチャ」でオフにできます。
