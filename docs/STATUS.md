## 既知の問題

- Windows 実機での動作は未確認（Wine 9.0 + Mesa llvmpipe で確認）。
- 建物の上には乗れない（地形のみ歩行）。駅のデッキや歩道橋は通れない。
- PLATEAU の LOD2 屋根外形（lod0RoofEdge）で衝突判定しているため、庇の下に入れない場合がある。
- テクスチャアトラスはセル単位で一様縮小（約 0.3 倍）しているため、近くで見ると粗い。
- 歩く住民は歩道と車道を区別せず、車道の中央を歩くことがある（歩道優先のコストは未実装）。人同士の回避も無い。
- 時間圧縮（既定 30 倍）でも歩行者は現実の速度（1.4 m/s）で歩くため、到着時刻は予定とずれる。
- 都市設備（信号・照明・柵・標示）の PLATEAU データは渋谷駅東側（明治通り・宮益坂周辺）のみで、スクランブル交差点には無い。
- 渋谷駅周辺は再開発が続いており、PLATEAU（2025 年度データ）と現況が異なる場合がある。
